# v1.0.0 notebooks (superseded)

These are the notebooks of the first submission, unchanged from release v1.0.0
(https://doi.org/10.5281/zenodo.19066198). The revised analysis in the top folder replaces
them, and some of the conclusions drawn from them no longer stand: see the main
[README](../README.md#what-changed-from-v100).

The notebooks read the data files by bare file name. To re-run one, copy the four CSV files
from [`../data`](../data) into its working directory.

`../reviewer_checks.py` re-runs the statistics of these notebooks on the same data
(section 1 of `../results/reviewer_checks.txt`).
